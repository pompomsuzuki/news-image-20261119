# The World in One Day — 19 November 2026

A program that draws one image summing up the world news of Thursday
19 November 2026, newspaper front-page style.

Run it (Python 3.13, standard library only, no network):

    python3 main.py

It writes `/output/entry.png` (set `MAKEFUN_OUTPUT_DIR` to write
elsewhere). The output is deterministic: every run writes the same
bytes. The image is 1024x1024 and well under 1 MiB.

The five stories on the page:

1. Trump, Xi and Putin hold their first trilateral summit in
   Shenzhen; their joint declaration reaffirms that a nuclear war
   must never be fought.
2. The International Court of Justice rules that Myanmar committed
   genocide against the Rohingya.
3. Grand Theft Auto VI launches, 13 years after GTA V.
4. NASA confirms Voyager 1 has reached one light-day from Earth.
5. Anthropic (ANT) debuts on Nasdaq in the biggest IPO on record.
